# 06. 금융상품 기본 분류

## 왜 중요한가

상품별로 현금흐름, 위험, 평가 방식, 회계 처리 방식이 다르다. 상품 분류가 모호하면 시스템 전체가 예외 처리 집합이 된다.

## 핵심 이론

주요 상품군:

- 현금성 자산
- 예금
- 대출채권
- 회사채/사채
- 지분상품
- 수익증권/펀드지분
- 파생상품

각 상품군은 다음에서 차이를 가진다.

- 현금흐름 구조
- 만기 유무
- 이자 또는 배당 구조
- 원금 회수 방식
- 평가 방식
- 손상 판단 방식

## 반드시 이해해야 하는 개념

- 상품 분류는 단순 이름이 아니라 회계정책 분기의 기준이다.
- 동일 상품명도 계약 조건에 따라 실질이 다를 수 있다.
- 복합상품은 여러 회계 구성요소로 쪼개야 할 수 있다.

## 읽고 확인할 질문

- 이 상품은 채권성인가 지분성인가
- 현금흐름이 확정적인가 성과연동적인가
- 만기와 상환 구조는 어떤가

## 개발 기준

- 상품 유형은 회계 규칙 선택의 입력값이어야 한다.
- 상품 마스터에는 현금흐름 구조와 평가 분류 기준이 포함돼야 한다.
- 이름 중심 분기보다 계약 속성 중심 분기를 우선한다.
