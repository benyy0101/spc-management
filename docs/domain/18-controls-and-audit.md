# 18. 내부통제와 감사 관점

## 왜 중요한가

회계 시스템은 맞는 숫자만이 아니라 설명 가능한 숫자를 만들어야 한다. 감사 대응과 내부통제는 기능 부가물이 아니라 핵심 요구사항이다.

## 핵심 이론

- 입력, 승인, 마감, 수정 권한은 분리될 수 있다.
- 수기분개는 통제 강도가 높아야 한다.
- 원천 거래부터 재무제표까지 추적 가능해야 한다.
- 변경 이력은 사후 설명 가능성을 만든다.

## 반드시 이해해야 하는 개념

- 감사인은 숫자뿐 아니라 근거와 절차를 본다.
- 누가 언제 무엇을 바꿨는지가 중요하다.
- 마감 이후 무통제 수정은 치명적이다.

## 읽고 확인할 질문

- 분개 생성 근거를 어떤 수준까지 저장할 것인가
- 승인 없이 반영 가능한 거래는 무엇인가
- 수기 조정은 어떤 증빙을 남겨야 하는가

## 개발 기준

- 모든 회계 수정은 사용자, 시각, 사유를 기록한다.
- 자동분개도 계산 근거를 재현 가능해야 한다.
- 승인 절차가 필요한 기능은 도메인 요구사항으로 취급한다.
