# 01. 회계의 기본 흐름

## 왜 중요한가

이 시스템의 핵심은 금융상품 관리가 아니라 거래를 회계 숫자로 바꾸는 과정이다. 거래, 분개, 원장, 시산표, 재무제표의 흐름을 이해하지 못하면 아키텍처도 흔들린다.

## 핵심 이론

- 거래는 경제적 사건이다.
- 분개는 거래를 차변과 대변으로 표현한 회계 기록이다.
- 원장은 분개가 계정별로 누적된 결과다.
- 시산표는 계정 잔액 검증 도구다.
- 재무제표는 시산표를 분류하고 요약한 보고서다.

기본 흐름:

`거래 -> 분개 -> 원장 -> 시산표 -> 재무제표`

## 반드시 이해해야 하는 개념

- 차변과 대변은 증가/감소의 방향이 아니라 계정 성격에 따라 해석된다.
- 발생주의에서는 현금 수수와 무관하게 수익과 비용이 인식될 수 있다.
- 수정분개와 결산분개는 원천 거래가 없어도 필요할 수 있다.
- 역분개는 다음 기간의 중복 인식을 막기 위한 처리다.

## 읽고 확인할 질문

- 거래와 분개의 차이를 설명할 수 있는가
- 현금 수취 없이 이자수익이 인식될 수 있는가
- 결산 시 왜 추가 분개가 필요한가
- 잔액 검증은 어느 단계에서 수행되는가

## 개발 기준

- 모든 회계 기능은 분개 생성 가능성을 기준으로 정의한다.
- 원천 거래와 분개는 별도 객체로 구분한다.
- 재무제표는 직접 입력하지 않고 원장 집계의 결과물이어야 한다.
- 수동 조정분개도 동일한 원장 흐름에 편입되어야 한다.
