# 09. 평가와 측정

## 왜 중요한가

금융상품은 취득원가만으로 끝나지 않는다. 보고 기준에 따라 상각후원가나 공정가치로 다시 측정할 수 있고, 이는 손익과 자본에 직접 영향을 준다.

## 핵심 이론

- 취득원가: 최초 인식 금액 중심
- 상각후원가: 유효이자율과 상환 스케줄 반영
- 공정가치: 시장 또는 평가기법 기반 현재 가치

## 반드시 이해해야 하는 개념

- 평가손익과 실현손익은 다르다.
- 시장가격이 없는 자산은 모델 기반 평가가 필요하다.
- 평가 기준일은 보고 시점과 일치해야 한다.
- 평가 분류는 회계정책의 결과다.

## 읽고 확인할 질문

- 이 상품은 어떤 측정 기준을 적용하는가
- 평가손익은 PL인가 자본인가
- 시장가격이 없을 때 어떤 입력값을 쓸 것인가

## 개발 기준

- 평가 기준과 입력값 출처를 저장해야 한다.
- 평가 이벤트와 현금 이벤트를 분리한다.
- 동일 상품도 회계 기준별 장부 값이 다를 수 있음을 허용한다.
