# 21. 반드시 설명할 수 있어야 하는 핵심 시나리오

## 왜 중요한가

도메인 이해는 정의 암기가 아니라 시나리오 설명 능력으로 검증된다. 아래 흐름을 분개와 잔액 변화까지 설명할 수 있어야 한다.

## 핵심 시나리오

1. 투자자가 펀드에 출자한다.
2. 펀드가 SPC에 자금을 투입한다.
3. SPC가 선박 관련 자산을 취득한다.
4. SPC 또는 관련 주체가 차입을 일으킨다.
5. 월말 이자가 발생한다.
6. 실제로 이자를 수취한다.
7. 운용보수가 발생한다.
8. 평가손익을 반영한다.
9. 원금을 일부 상환한다.
10. 결산 후 재무제표를 만든다.

## 각 시나리오에서 반드시 말할 수 있어야 하는 것

- 회계주체는 누구인가
- 현금 이동이 있는가
- 어떤 계정이 변하는가
- 분개는 무엇인가
- 잔액과 보고서에 어떤 영향이 있는가

## 개발 기준

- 신규 기능은 최소 하나의 핵심 시나리오에 연결돼야 한다.
- 시나리오 단위 예제 데이터와 기대 분개를 유지한다.
- 회계 로직 검증은 시나리오 기반으로 수행한다.
