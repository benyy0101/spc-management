# 14. 펀드 도메인

## 왜 중요한가

펀드는 투자자 자금 모집과 배분의 단위이며, 투자대상인 SPC와 다르다. 펀드 회계, 투자자 지분 관리, NAV 계산은 별도의 도메인이다.

## 핵심 이론

- 펀드는 출자약정과 납입 구조를 가진다.
- 투자자는 펀드 지분을 보유하고, 펀드는 투자대상을 보유한다.
- NAV는 펀드 순자산가치를 의미한다.
- 운용보수, 성과보수, 수탁보수 등 보수 체계가 별도로 존재한다.

## 반드시 이해해야 하는 개념

- 펀드 단계 손익과 투자대상 단계 손익은 다르다.
- 투자자별 지분율과 손익 배분 규칙이 필요하다.
- 자금 납입과 회계 수익 배분은 같은 사건이 아니다.

## 읽고 확인할 질문

- 약정총액과 납입총액은 어떻게 다른가
- 투자자별 지분 변동은 어떤 이벤트로 발생하는가
- NAV와 재무제표 자본총계는 항상 같은가

## 개발 기준

- 펀드와 투자대상 엔터티를 분리한다.
- 투자자 단위 배분 규칙과 펀드 단위 장부를 구분한다.
- 보수 계산과 회계 인식은 연결되되 별도 규칙으로 관리한다.
