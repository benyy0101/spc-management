# 11. 외화

## 왜 중요한가

선박 금융과 해외 자산은 외화 이슈가 매우 크다. 거래통화, 기능통화, 보고통화가 다르면 환산 기준을 분명히 해야 한다.

## 핵심 이론

- 거래통화: 실제 거래가 발생한 통화
- 기능통화: 해당 회계주체가 주로 사용하는 통화
- 보고통화: 재무제표 표시 통화

외화 회계에서는 다음이 중요하다.

- 최초 인식 환율
- 결산일 환율
- 결제일 환율
- 환산손익 인식 위치

## 반드시 이해해야 하는 개념

- 외화 현금흐름 손익과 환율 손익은 구분된다.
- 자산과 부채의 환산 기준이 다를 수 있다.
- 같은 거래도 시점별 환율 적용 결과가 다르다.

## 읽고 확인할 질문

- 어떤 환율을 어느 날짜에 적용하는가
- 평가손익과 환산손익은 어떻게 구분하는가
- 보고통화 변환은 어디서 수행하는가

## 개발 기준

- 거래통화 금액과 보고통화 금액을 모두 추적한다.
- 환율 출처와 적용일을 보존한다.
- 외화 재평가와 상품 평가를 अलग개 이벤트로 관리한다.
