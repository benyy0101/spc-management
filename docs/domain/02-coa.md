# 02. COA(계정과목체계)

## 왜 중요한가

COA는 회계 시스템의 언어다. 동일한 거래라도 어떤 계정으로 분류하느냐에 따라 재무제표와 관리 보고가 달라진다.

## 핵심 이론

- COA는 계정과목의 표준 분류 체계다.
- 기본 분류는 자산, 부채, 자본, 수익, 비용이다.
- 계정은 재무제표 라인과 연결되고, 차원은 분석 목적 정보를 제공한다.

예시:

- 현금및현금성자산
- 예치금
- 대출채권
- 미수수익
- 선수수익
- 이자수익
- 평가손익
- 외환차손익

## 반드시 이해해야 하는 개념

- 계정과목과 관리항목은 다르다.
- 동일한 대출채권 계정도 펀드, SPC, 상품, 거래상대방 차원으로 나눠 봐야 할 수 있다.
- COA는 보고 목적과 감사 대응을 고려해 설계해야 한다.
- 법인 공통 COA와 딜 단위 보조 구분은 분리해 생각해야 한다.

## 읽고 확인할 질문

- 계정과 차원의 역할이 왜 다른가
- 상품별 잔액 관리를 계정만으로 처리할 수 있는가
- 재무제표 라인과 계정 매핑은 어디서 통제할 것인가

## 개발 기준

- 계정과 차원을 혼합한 설계를 피한다.
- 재무제표 매핑 가능한 COA를 먼저 정의한다.
- 계정 추가 없이 차원 확장으로 해결 가능한 요구는 차원으로 처리한다.
- 회계주체별 COA 적용 범위와 공통 코드를 분리해 관리한다.
